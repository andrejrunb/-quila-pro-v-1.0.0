---
description: Guia para implementação de novas funcionalidades seguindo o padrão Sovereign OS.
---

Este workflow orienta o Antigravity na criação de código que respeita o "Deep Tech Moat" do Áquila.

1. Pesquisar o Vault (`.aquila_brain`) por restrições arquiteturais relacionadas à nova feature.
2. Definir se o processamento é **Edge-First** (Local) ou **Cloud-Secondary**.
3. Implementar a lógica de UI usando o **Elite UI System** (Vanilla CSS + Glint).
4. Ativar as skills pertinentes (`lgpd_guard`, `npu_optimizer`) durante a codificação.
5. Criar testes unitários e integrados.
