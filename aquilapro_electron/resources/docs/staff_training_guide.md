# Guia de Treinamento: Áquila Pro v1.0
## Para Coordenadores e Secretários Escolares

### 1. Entendendo o Sistema
O Áquila Pro não é apenas uma câmera de segurança. É uma **IA de Engajamento**.
- **Reconhecimento Facial:** Ocorre na entrada e em salas de aula.
- **Privacidade:** Nenhuma foto sai da escola. Tudo é processado no servidor local.
- **WhatsApp:** Os pais recebem alertas de segurança e confirmação de presença.

### 2. Rotina Diária
- **07:00:** Verifique o painel "Active Streams" para garantir que todas as câmeras estão online.
- **08:00:** Monitore a aba "Relatórios de Atraso" para identificar alunos que chegaram após o início das aulas.
- **12:00:** Verifique os "Insights de Risco" (Alunos com alta taxa de ausência ou mudança de comportamento).

### 3. Gestão de Alunos
- **Importação:** Utilize o "Batch Importer" para subir fotos de novos alunos. Use o padrão `nome_completo.jpg`.
- **Alertas de Segurança:** Se o sistema detectar um "SPOOFING" (aluno usando foto no celular), o monitor de pátio deve ser avisado imediatamente para orientação pedagógica.

### Suporte Técnico
- Em caso de travamento: O sistema possui um "Watchdog" que reinicia sozinho em até 3 segundos.
- Backup: Ocorre automaticamente todo domingo à meia-noite.
