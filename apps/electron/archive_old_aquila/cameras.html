O Áquila funciona com praticamente qualquer câmera IP do mercado. Compatibilidade universal via RTSP/ONVIF.

Especificações Técnicas Suportadas

Protocolos
  • RTSP (Real Time Streaming Protocol)
  • ONVIF (Open Network Video Interface Forum)
  • HTTP/HTTPS
  • MJPEG
Codecs de Vídeo
  • H.264
  • H.265 (HEVC)
  • MPEG-4
  • Motion JPEG
Resoluções
  • 720p (HD)
  • 1080p (Full HD)
  • 2MP, 4MP, 5MP
  • 4K (8MP+)
Conexão
  • Ethernet (PoE)
  • Wi-Fi
  • 4G/LTE
  • Híbrida

Guia de Instalação

Conectar Câmera

2
Obter IP

3

Testar
