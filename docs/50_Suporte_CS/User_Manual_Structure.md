# Estrutura do Manual do Usuário: Áquila Pro

Este documento define o esqueleto para a documentação de suporte e onboarding do sistema.

## 📁 Seções Principais

### 1. Guia para Coordenação (O Cérebro da Unidade)
- Dashboard principal: Como ler os indicadores de segurança.
- Mapeamento de Sala: Gerenciando 'Pins' e sugestões da IA.
- Gestão de Alertas: O que fazer quando o pânico é disparado.

### 2. Guia para Professores (Suporte Pedagógico)
- Chamada Automática: Como verificar a presença em tempo real.
- Relatórios de Turma: Identificando alunos com risco de evasão.
- Feedback Comportamental: Como inserir observações no sistema.

### 3. Guia de Administração & TI (Infraestrutura)
- Setup de Câmeras: Protocolos RTSP e calibração de faces.
- Backup & Segurança: Gestão da base SQLite e chaves de criptografia.
- Troubleshooting: Resolvendo problemas comuns de rede.

### 4. Portal para Pais (Transparência)
- Como instalar o app `Áquila Parent`.
- Privacidade: O que a escola vê e o que os pais recebem.
- Autorização de Saída: O uso do QR Code dinâmico.
