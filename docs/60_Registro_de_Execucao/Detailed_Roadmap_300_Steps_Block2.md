# Áquila OS: Roadmap de Execução (Bloco 2: Passos 301-600)

Este documento detalha a execução da segunda grande fase (**v1941 a v2240**), focando em inteligência afetiva e persistência de rastreamento.

---

## 🛡️ Squad 1: Persistência de Segurança (Re-ID & Gait)
*Agentes: SecurityAgent, AuditorAgent*
*Foco: Continuidade de rastreamento sem interrupção (Passos 301–400)*

301. [ ] Implementar `ReIDPersistenceService` para manter o ID do aluno entre áreas sem cobertura de face.
302. [ ] Treinar modelo de "Gait Analysis" (Caminhada) para reforçar a identidade em longas distâncias.
303. [ ] Integrar Re-ID com o `PredictiveSafetyService` para rastrear anomalias em múltiplos níveis.
304. [ ] Sistema de "Fronteira Invisível": Alerta iminente antes de alguém abrir áreas proibidas.
305. [ ] Auditoria de "Shadow Zones": O Agente sugere novos ângulos de câmera para cobrir pontos cegos detectados pelo enxame.
*(Avançar para persistência total em campos abertos até o passo 400...)*

---

## 🧠 Squad 2: Inteligência Afetiva (Micro-Expressions)
*Agentes: TeacherAgent, StudentAgent*
*Foco: Empatia AI e Ajuste Curricular Dinâmico (Passos 401–500)*

401. [ ] Ativar `MicroExpressionService`: Detectar tédio, frustração ou alegria em tempo real na aula.
402. [ ] Alimentar o `MotivationBot` com métricas afetivas para prever abandono escolar prematuro.
403. [ ] Criar "Alertas de Frustração": Sugerir pausa ou troca de atividade para o professor via `TeacherDashboard`.
404. [ ] Implementar "Diário Afetivo": O pai recebe um resumo do estado emocional predominante do dia.
405. [ ] Refinar "Mapa de Interesses" com base nas expressões de maior engajamento durante os tópicos.
*(Evoluir para empatia profunda aluno-sistema até o passo 500...)*

---

## ⚙️ Squad 3: Automação Preditiva Financeira & ERP
*Agentes: FinanceAgent, AdminAgent*
*Foco: Sustentabilidade e Previsibilidade Total (Passos 501–600)*

501. [ ] Implementar `FinancialForecastingService`: Prever inadimplência baseada em comportamento histórico.
502. [ ] Automação de Compras 2.0: O sistema gera pedidos de reposição baseados em consumo previsto.
503. [ ] Integração total com Bancos (Open Banking/Webhook) para baixa automática de 100% dos títulos.
504. [ ] Sistema de "Venda de Upgrade": IA sugere cursos extracurriculares baseada no perfil afetivo/pedagógico.
505. [ ] Dashboards Executivos de "LTV" (Lifetime Value) para o dono da escola por aluno.
*(Consolidar autonomia administrativa total até o passo 600...)*

## ✅ Meta Final do Bloco 600: v2240
Ao final desta fase, o Áquila OS deixará de ser apenas "Inteligente" para se tornar **"Empático e Omnipresente"**, entendendo os sentimentos dos alunos e mantendo a segurança sem falhas de continuidade.
