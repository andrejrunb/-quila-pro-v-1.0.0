# 📱 Análise: APIs Gratuitas de WhatsApp para Áquila Pro\n\n## 📋 Resumo Executivo\n\nExistem **3 opções viáveis** para enviar mensagens WhatsApp gratuitamente:\n\n1. ✅ **WhatsApp Business API (Meta)** - Gratuito com limite\n2. ✅ **Evolution API** - Open-source, self-hosted\n3. ✅ **Baileys** - Node.js library, simples\n\n---\n\n## 🥇 Opção 1: WhatsApp Business API (Meta) - Recomendado\n\n### O que é\n\nAPI oficial do WhatsApp fornecida pela Meta (Facebook) para negócios\n\n### Preços\n\n| Tipo | Custo | Limite |\n|------|-------|--------|\n| **Sandbox** | Gratuito | 100 mensagens/dia |\n| **Produção** | $0.0035-0.0500 por msg | Ilimitado |\n\n### Como Funciona\n\n```\n1. Criar conta Business na Meta\n2. Solicitar acesso à API\n3. Configurar webhook para receber mensagens\n4. Enviar mensagens via API REST\n```\n\n### Vantagens\n\n✅ Oficial e confiável\n✅ Sandbox gratuito (100 msgs/dia)\n✅ Muito simples de integrar\n✅ Suporta templates de mensagens\n✅ Webhooks para receber respostas\n✅ Analytics integrado\n\n### Desvantagens\n\n❌ Requer verificação de negócio\n❌ Requer número de telefone dedicado\n❌ Pago em produção ($0.0035-0.05 por msg)\n❌ Limite de 100 msgs/dia em sandbox\n\n### Implementação\n\n```typescript\n// WhatsAppBusinessAPI.ts\n\nexport class WhatsAppBusinessAPI {\n  private accessToken: string;\n  private phoneNumberId: string;\n  private apiUrl = 'https://graph.instagram.com/v18.0';\n\n  constructor(accessToken: string, phoneNumberId: string) {\n    this.accessToken = accessToken;\n    this.phoneNumberId = phoneNumberId;\n  }\n\n  async sendMessage(to: string, message: string): Promise<any> {\n    const url = `${this.apiUrl}/${this.phoneNumberId}/messages`;\n\n    const response = await fetch(url, {\n      method: 'POST',\n      headers: {\n        'Authorization': `Bearer ${this.accessToken}`,\n        'Content-Type': 'application/json',\n      },\n      body: JSON.stringify({\n        messaging_product: 'whatsapp',\n        to,\n        type: 'text',\n        text: { body: message },\n      }),\n    });\n\n    return response.json();\n  }\n\n  async sendTemplate(\n    to: string,\n    templateName: string,\n    parameters: string[]\n  ): Promise<any> {\n    const url = `${this.apiUrl}/${this.phoneNumberId}/messages`;\n\n    const response = await fetch(url, {\n      method: 'POST',\n      headers: {\n        'Authorization': `Bearer ${this.accessToken}`,\n        'Content-Type': 'application/json',\n      },\n      body: JSON.stringify({\n        messaging_product: 'whatsapp',\n        to,\n        type: 'template',\n        template: {\n          name: templateName,\n          language: { code: 'pt_BR' },\n          parameters: {\n            body: {\n              parameters: parameters.map(p => ({ type: 'text', text: p })),\n            },\n          },\n        },\n      }),\n    });\n\n    return response.json();\n  }\n}\n```\n\n### Custo para Escola com 500 alunos\n\n```\nCenário: 2 alertas por aluno por dia, 250 dias úteis\n\nMensagens/dia: 500 alunos × 2 alertas = 1,000 msgs\nMensagens/mês: 1,000 × 22 dias = 22,000 msgs\nMensagens/ano: 22,000 × 12 = 264,000 msgs\n\nCusto (taxa média $0.0035):\n264,000 × $0.0035 = $924/ano\n\nCusto (taxa máxima $0.05):\n264,000 × $0.05 = $13,200/ano\n```\n\n---\n\n## 🥈 Opção 2: Evolution API - Open-Source\n\n### O que é\n\nAPI open-source que funciona como \"proxy\" do WhatsApp, permitindo enviar mensagens sem custos\n\n### Preços\n\n| Tipo | Custo |\n|------|-------|\n| **Self-hosted** | Gratuito |\n| **Cloud** | $9.99-99.99/mês |\n\n### Como Funciona\n\n```\n1. Instalar Evolution API em servidor próprio\n2. Conectar conta WhatsApp pessoal/business\n3. Usar API para enviar mensagens\n4. Sem limites de mensagens\n```\n\n### Vantagens\n\n✅ Completamente gratuito (self-hosted)\n✅ Sem limites de mensagens\n✅ Open-source\n✅ Funciona com WhatsApp pessoal ou Business\n✅ Suporta múltiplas contas\n✅ Webhooks para eventos\n\n### Desvantagens\n\n❌ Requer servidor próprio\n❌ Mais complexo de configurar\n❌ Pode ser bloqueado pelo WhatsApp (risco)\n❌ Requer manutenção técnica\n❌ Não é oficial da Meta\n\n### Instalação\n\n```bash\n# Docker\ndocker run -d \\\n  -p 8080:8080 \\\n  -e DATABASE_CONNECTION_URI=mongodb://mongo:27017 \\\n  -e JWT_SECRET=seu-secret \\\n  --name evolution-api \\\n  evolucaocodes/evolution-api:latest\n\n# Acessar em http://localhost:8080\n```\n\n### Implementação\n\n```typescript\n// EvolutionAPIIntegration.ts\n\nexport class EvolutionAPIIntegration {\n  private baseUrl: string;\n  private apiKey: string;\n\n  constructor(baseUrl: string, apiKey: string) {\n    this.baseUrl = baseUrl;\n    this.apiKey = apiKey;\n  }\n\n  async sendMessage(instanceName: string, to: string, message: string): Promise<any> {\n    const response = await fetch(\n      `${this.baseUrl}/message/sendText/${instanceName}`,\n      {\n        method: 'POST',\n        headers: {\n          'Content-Type': 'application/json',\n          'apikey': this.apiKey,\n        },\n        body: JSON.stringify({\n          number: to,\n          text: message,\n        }),\n      }\n    );\n\n    return response.json();\n  }\n\n  async sendMedia(\n    instanceName: string,\n    to: string,\n    mediaUrl: string,\n    caption: string\n  ): Promise<any> {\n    const response = await fetch(\n      `${this.baseUrl}/message/sendMedia/${instanceName}`,\n      {\n        method: 'POST',\n        headers: {\n          'Content-Type': 'application/json',\n          'apikey': this.apiKey,\n        },\n        body: JSON.stringify({\n          number: to,\n          mediaType: 'image',\n          media: mediaUrl,\n          caption,\n        }),\n      }\n    );\n\n    return response.json();\n  }\n}\n```\n\n### Custo para Escola\n\n```\nSelf-hosted: $0/ano (apenas eletricidade ~$20)\nCloud: $120-1,200/ano\n```\n\n---\n\n## 🥉 Opção 3: Baileys - Node.js Library\n\n### O que é\n\nBiblioteca Node.js que simula cliente WhatsApp Web\n\n### Preços\n\n| Tipo | Custo |\n|------|-------|\n| **NPM** | Gratuito |\n\n### Como Funciona\n\n```\n1. Instalar via npm\n2. Conectar com QR code\n3. Enviar mensagens via código\n4. Sem API, sem custos\n```\n\n### Vantagens\n\n✅ Completamente gratuito\n✅ Muito simples de usar\n✅ Sem servidor adicional\n✅ Funciona com WhatsApp pessoal\n✅ Suporta múltiplos tipos de mensagens\n\n### Desvantagens\n\n❌ Pode ser bloqueado pelo WhatsApp\n❌ Menos confiável que API oficial\n❌ Requer manutenção frequente\n❌ Não é suportado pela Meta\n❌ Risco de banimento\n\n### Instalação\n\n```bash\nnpm install @whiskeysockets/baileys\n```\n\n### Implementação\n\n```typescript\n// BaileysIntegration.ts\n\nimport makeWASocket from '@whiskeysockets/baileys';\nimport { DisconnectReason } from '@whiskeysockets/baileys';\n\nexport class BaileysIntegration {\n  private sock: any;\n\n  async connect(): Promise<void> {\n    const sock = makeWASocket({\n      auth: {\n        creds: {},\n        keys: {},\n      },\n    });\n\n    sock.ev.on('connection.update', (update: any) => {\n      const { connection, lastDisconnect } = update;\n      if (connection === 'close') {\n        const shouldReconnect =\n          lastDisconnect?.error?.output?.statusCode !== DisconnectReason.loggedOut;\n        console.log(\n          'connection closed due to ',\n          lastDisconnect?.error,\n          ', reconnecting ',\n          shouldReconnect\n        );\n      }\n    });\n\n    this.sock = sock;\n  }\n\n  async sendMessage(to: string, message: string): Promise<void> {\n    await this.sock.sendMessage(to, { text: message });\n  }\n\n  async sendMedia(to: string, mediaUrl: string, caption: string): Promise<void> {\n    const media = await fetch(mediaUrl).then(r => r.buffer());\n    await this.sock.sendMessage(to, {\n      image: media,\n      caption,\n    });\n  }\n}\n```\n\n---\n\n## 📊 Comparação das 3 Opções\n\n| Critério | Meta API ${alertType}`;\n\n    try {\n      if (alertType === 'critical') {\n        // Usar Meta API para alertas críticos\n        await this.metaAPI.sendMessage(parentPhone, message);\n      } else {\n        // Usar Evolution API para notificações gerais\n        await this.evolutionAPI.sendMessage('default', parentPhone, message);\n      }\n    } catch (error) {\n      // Fallback para email\n      await this.emailService.sendAlert(parentPhone, message);\n    }\n  }\n}\n```\n\n---\n\n## 💰 Custo Anual Comparativo\n\n### Escola com 500 alunos\n\n| Solução | Custo Anual | Confiabilidade | Recomendação |\n|---------|-----------|---------------|--------------|\n| **Meta API** | $900 | Máxima | ✅ Melhor |\n| **Evolution API** | $0 | Boa | ✅ Bom |\n| **Baileys** | $0 | Baixa | ❌ Risco |\n| **Híbrida** | $900 | Máxima | ✅ Ideal |\n\n---\n\n## ✅ Próximos Passos\n\n1. **Escolher Estratégia**\n   -
