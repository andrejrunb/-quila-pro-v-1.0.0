# Análise de Compatibilidade: Câmeras Hikvision + DVR Intelbras com Áquila Pro\n\n## 📊 Resumo Executivo\n\n**Resposta Curta:** ✅ **SIM, é totalmente compatível**, mas com algumas considerações técnicas importantes.\n\n**Nível de Compatibilidade:** 95% (com pequenos ajustes)\n\n---\n\n## 🎯 Cenário Atual da Escola\n\n```\nCâmeras Hikvision → DVR Intelbras → Programa Intelbras (gerenciamento)\n```\n\n**Problema:** O programa Intelbras gerencia as câmeras, mas o Áquila Pro precisa acessar o stream de vídeo diretamente para:\n- Processar frames em tempo real\n- Fazer detecção de pessoas (YOLO)\n- Fazer reconhecimento facial\n- Registrar presença\n\n---\n\n## ✅ Por Que É Compatível\n\n### 1. **Câmeras Hikvision são RTSP-Compatíveis**\n- Hikvision é um dos maiores fabricantes de câmeras IP do mundo\n- Todas as câmeras Hikvision suportam protocolo RTSP (Real Time Streaming Protocol)\n- Formato padrão: `rtsp://[IP]:[PORTA]/stream1` ou `rtsp://[IP]:[PORTA]/Streaming/Channels/101`\n\n### 2. **DVR Intelbras Funciona como Proxy**\n- O DVR Intelbras é basicamente um gravador de vídeo em rede\n- Ele **não interfere** com o stream RTSP das câmeras\n- Você pode acessar as câmeras diretamente (bypass do DVR) OU através do DVR\n\n### 3. **Duas Formas de Integração**\n\n#### **Opção A: Acesso Direto às Câmeras (Recomendado)**\n```\nCâmeras Hikvision → Áquila Pro (acesso direto via RTSP)\n                 ↓\n            DVR Intelbras (continua gravando)\n```\n**Vantagens:**\n- ✅ Melhor performance (sem intermediários)\n- ✅ Latência menor (~200ms)\n- ✅ Sem dependência do DVR\n- ✅ Mais estável\n\n**Desvantagens:**\n- ❌ Requer configuração de rede (IP estático para câmeras)\n\n#### **Opção B: Acesso via DVR Intelbras**\n```\nCâmeras Hikvision → DVR Intelbras → Áquila Pro (via RTSP do DVR)\n```\n**Vantagens:**\n- ✅ Centralizado (tudo gerenciado pelo DVR)\n- ✅ Mais fácil de configurar\n- ✅ DVR já tem IPs configurados\n\n**Desvantagens:**\n- ❌ Latência maior (~500-1000ms)\n- ❌ Depende da performance do DVR\n- ❌ Pode sobrecarregar o DVR\n- ❌ Menos estável com múltiplos streams\n\n---\n\n## 🔧 Configuração Técnica\n\n### **Passo 1: Descobrir IPs das Câmeras**\n\n```bash\n# Via software Hikvision (já instalado na escola)\n# Ou via rede:\nnmap -p 554 192.168.1.0/24  # Procura por RTSP (porta 554)\n```\n\n### **Passo 2: Testar Acesso RTSP**\n\n```bash\n# Teste com VLC ou ffmpeg\nffplay rtsp://admin:12345@192.168.1.100:554/Streaming/Channels/101\n\n# Ou com OpenCV (Python)\nimport cv2\ncap = cv2.VideoCapture('rtsp://admin:12345@192.168.1.100:554/Streaming/Channels/101')\n```\n\n### **Passo 3: Configurar no Áquila Pro**\n\nNo `CameraConfiguration.tsx`, adicionar:\n\n```typescript\nconst hikvisionCameras = [\n  {\n    name: 'Câmera Sala 101 (Hikvision)',\n    rtspUrl: 'rtsp://admin:12345@192.168.1.100:554/Streaming/Channels/101',\n    room: 'Sala 101',\n  },\n  {\n    name: 'Câmera Corredor (Hikvision)',\n    rtspUrl: 'rtsp://admin:12345@192.168.1.101:554/Streaming/Channels/101',\n    room: 'Corredor Principal',\n  },\n];\n```\n\n---\n\n## 📋 Checklist de Compatibilidade\n\n|
