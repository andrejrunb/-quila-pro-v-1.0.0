# Guia de Processamento de Câmeras - Áquila Pro Desktop\n\n## 📹 Arquitetura de Processamento\n\nO sistema de processamento de câmeras é composto por 4 camadas principais:\n\n### 1. **VideoCapture** - Captura de Vídeo\n- Conecta a câmeras IP via RTSP/HTTP\n- Captura frames em tempo real\n- Gerencia múltiplas câmeras simultaneamente\n- Emite eventos de frame para processamento\n\n### 2. **FrameProcessor** - Processamento de Frames\n- Detecta pessoas usando YOLO/OpenCV\n- Rastreia movimento entre frames\n- Registra eventos de entrada/saída\n- Calcula confiança de detecção\n\n### 3. **PresenceTracker** - Rastreamento de Presença\n- Registra entrada de alunos em sala\n- Registra saída de alunos\n- Calcula duração em sala\n- Determina presença (75% threshold)\n\n### 4. **ProcessingPipeline** - Integração\n- Orquestra os 3 componentes acima\n- Gerencia eventos\n- Persiste dados no banco SQLite\n- Fornece API unificada\n\n---\n\n## 🔧 Configuração de Câmeras\n\n### Adicionar Câmera\n\n```typescript\nconst pipeline = new ProcessingPipeline(db);\n\npipeline.addCamera({\n  cameraId: 'cam-001',\n  cameraUrl: 'rtsp://192.168.1.101:554/stream',\n  location: 'Corredor Principal',\n  type: 'corridor',\n  resolution: { width: 1920, height: 1080 },\n  fps: 30,\n});\n\npipeline.addCamera({\n  cameraId: 'cam-002',\n  cameraUrl: 'rtsp://192.168.1.102:554/stream',\n  location: 'Porta Sala 101',\n  type: 'door',\n  classId: 'class-101',\n  resolution: { width: 1280, height: 720 },\n  fps: 24,\n});\n```\n\n### Iniciar Pipeline\n\n```typescript\nawait pipeline.start();\n\n// Monitorar eventos\npipeline.on('person:entry', (data) => {\n  console.log(`Pessoa detectada em ${data.cameraId}`);\n});\n\npipeline.on('presence:entry', (data) => {\n  console.log(`Aluno ${data.studentId} entrou em ${data.classId}`);\n});\n```\n\n---\n\n## 📊 Tipos de Câmeras\n\n### 1. **Corredor** (corridor)\n- Localização: Corredores da escola\n- Propósito: Rastreamento de movimento\n- Dados: Entrada/saída de áreas\n- Exemplo: Corredor principal, entre salas\n\n### 2. **Porta de Sala** (door)\n- Localização: Entrada de salas de aula\n- Propósito: Detecção de entrada/saída de alunos\n- Dados: Presença em sala\n- Vinculada a: classId\n\n### 3. **Entrada** (entrance)\n- Localização: Entrada principal da escola\n- Propósito: Controle de acesso\n- Dados: Chegadas/saídas da escola\n- Exemplo: Portão, recepção\n\n---\n\n## 🎯 Fluxo de Detecção\n\n```\nCâmera IP\n    ↓\n[VideoCapture] → Captura frames\n    ↓\n[FrameProcessor] → Detecta pessoas\n    ↓\n[Eventos: entry/exit]\n    ↓\n[PresenceTracker] → Registra presença\n    ↓\n[Database] → Persiste dados\n    ↓\n[Dashboard] → Exibe em tempo real\n```\n\n---\n\n## 📈 Eventos do Sistema\n\n### Eventos de Captura\n\n```typescript\npipeline.on('camera:started', (data) => {\n  console.log(`Câmera ${data.cameraId} iniciada`);\n});\n\npipeline.on('camera:stopped', (data) => {\n  console.log(`Câmera ${data.cameraId} parada`);\n});\n\npipeline.on('camera:error', (data) => {\n  console.error(`Erro na câmera ${data.cameraId}:`, data.error);\n});\n```\n\n### Eventos de Detecção\n\n```typescript\npipeline.on('person:entry', (data) => {\n  console.log(`Pessoa ${data.personId} entrou em ${data.cameraId}`);\n});\n\npipeline.on('person:exit', (data) => {\n  console.log(`Pessoa ${data.personId} saiu de ${data.cameraId}`);\n});\n```\n\n### Eventos de Presença\n\n```typescript\npipeline.on('presence:entry', (data) => {\n  console.log(`Aluno ${data.studentId} entrou em ${data.classId}`);\n});\n\npipeline.on('presence:exit', (data) => {\n  console.log(`Aluno ${data.studentId} saiu de ${data.classId} (${data.duration}min)`);\n});\n```\n\n---\n\n## 🔍 Detecção de Pessoas\n\n### Modelos Suportados\n\n1. **YOLO v8** (Recomendado)\n   - Velocidade: ~30 FPS em GPU\n   - Precisão: 95%+\n   - Tamanho: ~100 MB\n\n2. **OpenCV DNN**\n   - Velocidade: ~15 FPS em CPU\n   - Precisão: 90%\n   - Tamanho: ~50 MB\n\n3. **TensorFlow Lite**\n   - Velocidade: ~20 FPS em CPU\n   - Precisão: 92%\n   - Tamanho: ~30 MB\n\n### Configurar Modelo\n\n```typescript\nconst processor = pipeline.getManagers().processor.getProcessor('cam-001');\nprocessor.setModel('yolov8');\nprocessor.setConfidenceThreshold(0.7);\n```\n\n---\n\n## 📍 Rastreamento de Presença\n\n### Limiar de Presença\n\n```typescript\nconst presenceTracker = pipeline.getManagers().presence;\n\n// Configurar limiar de 75%\npresenceTracker.setPresenceThreshold(0.75);\n\n// Resultado:\n// >= 75% em sala = Presente\n// < 75% em sala = Ausente\n```\n\n### Calcular Presença\n\n```typescript\nconst presence = await pipeline.calculateStudentPresence(\n  'student-001',\n  'class-101',\n  new duration: 60,\n//   status: 'present',\n//   confidence: 0.95\n// }\n```\n\n---\n\n## 🗄️ Persistência de Dados\n\n### Tabelas SQLite\n\n```sql\n-- Eventos de câmera\nCREATE TABLE camera_events (\n  id INTEGER PRIMARY KEY,\n  camera_id TEXT,\n  event_type TEXT, -- 'entry', 'exit', 'error'\n  person_id TEXT,\n  timestamp DATETIME,\n  confidence REAL,\n  location TEXT\n);\n\n-- Presença de
