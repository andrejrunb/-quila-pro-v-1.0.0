Verificar cabo de rede\n2. Verificar PoE (Power over Ethernet)\n3. Reiniciar câmera\n4. Verificar IP da câmera\n5. Verificar firewall\n\n**Tempo**: 15 minutos\n\n### Detecção Baixa (<80%)\n\n**Sintoma**: Câmera não detecta alunos\n\n**Solução:**\n1. Verificar iluminação da sala\n2. Verificar ângulo da câmera\n3. Verificar resolução\n4. Retreinar reconhecimento facial\n5. Ajustar sensibilidade\n\n**Tempo**: 30 minutos\n\n### Reconhecimento Facial Impreciso\n\n**Sintoma**: Identifica aluno errado\n\n**Solução:**\n1. Coletar mais fotos do aluno\n2. Retreinar modelo\n3. Ajustar threshold de confiança\n4. Validar fotos de treinamento\n\n**Tempo**: 1 hora\n\n### Alertas Não Funcionam\n\n**Sintoma**: Não recebe notificações\n\n**Solução:**\n1. Verificar WhatsApp/Email\n2. Verificar configurações de alerta\n3. Testar alerta manualmente\n4. Verificar logs\n\n**Tempo**: 15 minutos\n\n### Latência Alta (>5s)\n\n**Sintoma**: Sistema lento\n\n**Solução:**\n1. Verificar CPU/RAM do servidor\n2. Verificar largura de banda\n3. Otimizar processamento\n4. Reduzir resolução\n5. Aumentar hardware\n\n**Tempo**: 1-2 horas\n\n---\n\n## 📞 Contatos de Suporte\n\n### Seu Contato\n\n```\nNome: André Jr\nEmail: andre.jr@yahoo.com\nWhatsApp: [seu número]\nHorário: 8h-18h (segunda a sexta)\nResponse Time: 2 horas\n```\n\n### Contato do Professor\n\n```\nNome: ___________\nEmail: ___________\nWhatsApp: ___________\nHorário de Aula: ___________\n```\n\n### Contato do Diretor\n\n```\nNome: ___________\nEmail: ___________\nWhatsApp: ___________\nHorário: ___________\n```\n\n---\n\n## 📋 Checklist Final (Antes de Começar)\n\n### Hardware\n\n- [ ] Câmera IP testada e funcionando\n- [ ] Cabos preparados (rede, PoE, HDMI)\n- [ ] Suporte de montagem preparado\n- [ ] Servidor preparado e testado\n- [ ] Armazenamento preparado\n- [ ] Backup preparado\n\n### Software\n\n- [ ] Sistema testado com 35 alunos\n- [ ] Banco de dados preparado\n- [ ] Reconhecimento facial treinado\n- [ ] Alertas testados\n- [ ] Dashboard testado\n- [ ] Logs configurados\n\n### Documentação\n\n- [ ] Termo LGPD preparado\n- [ ] Política de privacidade preparada\n- [ ] Manual do usuário preparado\n- [ ] FAQ preparado\n- [ ] Contatos de suporte preparados\n\n### Pessoal\n\n- [ ] Professor contatado e informado\n- [ ] Diretor informado\n- [ ] Pais informados (LGPD)\n- [ ] Alunos informados\n- [ ] Equipe de suporte preparada\n\n---\n\n## ✅ Conclusão\n\n**Você está pronto para começar!**\n\n**Próximos Passos:**\n\n1. **Esta Semana**: Escolher sala + Contatar professor\n2. **Próxima Semana**: Preparar hardware + software\n3. **Semana 3**: Instalar câmera\n4. **Semana 4**: Coletar dados\n5. **Semana 5**: Análise + Preparar Sala 2\n\n**Você consegue! 🚀**\n
