# Guia de Instalador e Deployment - Áquila Pro\n\n## 📦 Criando o Instalador Executável\n\n### Passo 1: Preparar Ambiente\n\n```bash\n# Instalar dependências de build\nnpm install -g electron-builder\nnpm install\n```\n\n### Passo 2: Build da Aplicação\n\n```bash\n# Build para produção\nnpm run build\n\n# Gerar executável\nnpm run electron:build\n```\n\n### Passo 3: Criar Instalador\n\n```bash\n# Configuração no package.json\n\"build\": {\n  \"appId\": \"com.aquilapro.desktop\",\n  \"productName\": \"Áquila Pro\",\n  \"files\": [\n    \"dist/**/*\",\n    \"node_modules/**/*\"\n  ],\n  \"win\": {\n    \"target\": [\n      \"nsis\",\n      \"portable\"\n    ]\n  },\n  \"nsis\": {\n    \"oneClick\": false,\n    \"allowToChangeInstallationDirectory\": true,\n    \"createDesktopShortcut\": true,\n    \"createStartMenuShortcut\": true\n  }\n}\n```\n\n### Passo 4: Gerar Arquivo .exe\n\n```bash\n# Build final\nelectron-builder --win --publish never\n\n# Resultado: dist/Áquila Pro Setup 1.0.0.exe\n```\n\n---\n\n## 🚀 Deployment em Servidor\n\n### Opção 1: Servidor Local (Recomendado para Escolas)\n\n```bash\n# 1. Instalar Node.js no servidor\nhttps://nodejs.org/en/download/\n\n# 2. Clonar repositório\ngit clone https://github.com/seu-usuario/aquila-pro.git\ncd aquila-pro\n\n# 3. Instalar dependências\nnpm install\n\n# 4. Configurar variáveis de ambiente\ncp .env.example .env\n# Editar .env com dados da escola\n\n# 5. Iniciar servidor\nnpm start\n\n# 6. Acessar em http://localhost:3000\n```\n\n### Opção 2: Cloud (AWS, Azure, Google Cloud)\n\n```bash\n# Exemplo com AWS EC2\n\n# 1. Criar instância EC2 (Ubuntu 20.04)\n# 2. SSH para instância\nssh -i chave.pem ubuntu@seu-ip\n\n# 3. Instalar dependências\nsudo apt update\nsudo apt install nodejs npm postgresql\n\n# 4. Clonar e configurar\ngit clone seu-repositorio\ncd aquila-pro\nnpm install\n\n# 5. Configurar PM2 para manter serviço rodando\nnpm install -g pm2\npm2 start npm --name \"aquila-pro\" -- start\npm2 startup\npm2 save\n\n# 6. Configurar Nginx como proxy\nsudo apt install nginx\n# Configurar /etc/nginx/sites-available/default\n```\n\n### Opção 3: Docker (Para Escalabilidade)\n\n```dockerfile\n# Dockerfile\nFROM node:18-alpine\n\nWORKDIR /app\n\nCOPY package*.json ./\nRUN npm install\n\nCOPY . .\n\nRUN npm run build\n\nEXPOSE 3000\n\nCMD [\"npm\", \"start\"]\n```\n\n```bash\n# Build e executar\ndocker build -t aquila-pro .\ndocker run -p 3000:3000 -e DATABASE_URL=postgresql://... aquila-pro\n```\n\n---\n\n## 📋 Checklist de Deployment\n\n### Antes do Deployment\n\n- [ ] Testar aplicação localmente\n- [ ] Executar testes automatizados\n- [ ] Validar segurança (OWASP Top 10)\n- [ ] Configurar HTTPS/SSL\n- [ ] Preparar banco de dados\n- [ ] Fazer backup de dados\n- [ ] Documentar processo\n\n### Durante o Deployment\n\n- [ ] Parar serviço anterior (se houver)\n- [ ] Fazer backup do banco de dados\n- [ ] Executar migrações\n- [ ] Iniciar novo serviço\n- [ ] Testar funcionalidades críticas\n- [ ] Monitorar logs\n- [ ] Validar performance\n\n### Após o Deployment\n\n- [ ] Notificar usuários\n- [ ] Monitorar sistema por 24h\n- [ ] Coletar feedback\n- [ ] Documentar issues\n- [ ] Preparar rollback se necessário\n\n---\n\n## 🔒 Segurança no Deployment\n\n### HTTPS/SSL\n\n```bash\n# Usar Let's Encrypt (gratuito)\nsudo apt install certbot python3-certbot-nginx\nsudo certbot certonly --nginx -d seu-dominio.com\n\n# Configurar Nginx\nserver {\n    listen 443 ssl http2;\n    server_name seu-dominio.com;\n    \n    ssl_certificate /etc/letsencrypt/live/seu-dominio.com/fullchain.pem;\n    ssl_certificate_key /etc/letsencrypt/live/seu-dominio.com/privkey.pem;\n    \n    location / {\n        proxy_pass http://localhost:3000;\n    }\n}\n```\n\n### Firewall\n\n```bash\n# Configurar UFW (Ubuntu)\nsudo ufw enable\nsudo ufw allow 22/tcp\nsudo ufw allow 80/tcp\nsudo ufw allow 443/tcp\nsudo ufw deny 3000/tcp  # Bloquear acesso direto\n```\n\n### Variáveis de Ambiente\n\n```bash\n# .env (nunca commitar)\nDATABASE_URL=postgresql://user:pass@localhost/aquila\nJWT_SECRET=seu-secret-aleatorio-muito-longo\nNODE_ENV=production\nAPI_KEY=sua-chave-api\n```\n\n---\n\n## 📊 Monitoramento\n\n### Logs\n\n```bash\n# Ver logs em tempo real\npm2 logs aquila-pro\n\n# Salvar logs\npm2 save\npm2 logs aquila-pro > /var/log/aquila-pro.log\n```\n\n### Métricas\n\n```bash\n# Instalar PM2 Plus (monitoramento)\npm2 install pm2-auto-pull\npm2 install pm2-logrotate\n\n# Dashboard\npm2 monit\n```\n\n### Alertas\n\n```bash\n# Configurar alertas de CPU/RAM\npm2 set pm2-auto-pull instances 4\npm2 set pm2-auto-pull max_memory_restart 1G\n```\n\n---\n\n## 🔄 Atualização e Rollback\n\n### Atualizar Aplicação\n\n```bash\n# 1. Fazer backup\npm2 backup\n\n# 2. Parar serviço\npm2 stop aquila-pro\n\n# 3. Atualizar código\ngit pull origin main\nnpm install\nnpm run build\n\n# 4. Executar migrações (se houver)\nnpm run migrate\n\n# 5. Reiniciar serviço\npm2 start aquila-pro\n\n# 6. Validar\ncurl http://localhost:3000/health\n```\n\n### Rollback (Se Algo Deu Errado)\n\n```bash\n# 1. Parar serviço\npm2 stop aquila-pro\n\n# 2. Voltar para versão anterior\ngit revert HEAD\nnpm install\n\n# 3. Restaurar banco de dados\npsql -U user -d aquila < backup.sql\n\n# 4. Reiniciar\npm2 start aquila-pro\n```\n\n---\n\n## 📈 Performance\n\n### Otimizações\n\n```bash\n# 1.
