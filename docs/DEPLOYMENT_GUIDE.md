# Guia de Deployment - Áquila Pro Desktop\n\n## 📦 Build para Produção\n\n### Windows\n\n```bash\n# Build da aplicação\npnpm run build:electron\n\n# Criar instalador\npnpm run dist:win\n\n# Resultado: aquila-pro-setup-1.0.0.exe\n```\n\n### macOS\n\n```bash\n# Build da aplicação\npnpm run build:electron\n\n# Criar DMG\npnpm run dist:mac\n\n# Resultado: Aquila-Pro-1.0.0.dmg\n```\n\n### Linux\n\n```bash\n# Build da aplicação\npnpm run build:electron\n\n# Criar AppImage\npnpm run dist:linux\n\n# Resultado: Aquila-Pro-1.0.0.AppImage\n```\n\n## 🔧 Configuração de Produção\n\n### Variáveis de Ambiente\n\nCriar arquivo `.env.production`:\n\n```env\n# Banco de Dados\nDATABASE_URL=mysql://user:password@host:3306/aquila_pro\nDATABASE_BACKUP_PATH=/opt/aquila-pro/backups\n\n# Segurança\nENCRYPTION_KEY=your-secure-key-here\nJWT_SECRET=your-jwt-secret-here\nBCRYPT_ROUNDS=12\n\n# Processamento\nMAX_CAMERAS=16\nFRAME_SKIP=2\nDETECTION_THRESHOLD=0.5\nFACE_RECOGNITION_THRESHOLD=0.6\n\n# WebSocket\nWS_PORT=9000\nWS_MAX_CONNECTIONS=100\n\n# Logging\nLOG_LEVEL=info\nLOG_RETENTION_DAYS=30\n\n# Backup\nBACKUP_INTERVAL_HOURS=24\nBACKUP_RETENTION_DAYS=30\n\n# Notificações\nSMTP_HOST=smtp.gmail.com\nSMTP_PORT=587\nSMTP_USER=your-email@gmail.com\nSMTP_PASSWORD=your-app-password\n```\n\n## 🚀 Instalação em Servidor\n\n### Requisitos de Sistema\n\n**Windows Server 2019+**\n- CPU: Intel i5 ou superior\n- RAM: 8GB mínimo, 16GB recomendado\n- Armazenamento: 100GB SSD\n- GPU: NVIDIA com CUDA (opcional, para melhor performance)\n\n**Linux (Ubuntu 20.04+)**\n- CPU: Intel i5 ou superior\n- RAM: 8GB mínimo, 16GB recomendado\n- Armazenamento: 100GB SSD\n- GPU: NVIDIA com CUDA (opcional)\n\n### Instalação no Windows\n\n```powershell\n# 1. Executar instalador\n.\\aquila-pro-setup-1.0.0.exe\n\n# 2. Seguir wizard de instalação\n# 3. Configurar banco de dados\n# 4. Iniciar serviço\nStart-Service AquilaPro\n\n# 5. Acessar dashboard\n# http://localhost:3000\n```\n\n### Instalação no Linux\n\n```bash\n# 1. Extrair AppImage\nchmod +x Aquila-Pro-1.0.0.AppImage\n./Aquila-Pro-1.0.0.AppImage --appimage-extract\n\n# 2. Instalar dependências\nsudo apt-get install -y libssl-dev libffi-dev python3-dev\npip install -r requirements.txt\n\n# 3. Criar serviço systemd\nsudo cp aquila-pro.service /etc/systemd/system/\nsudo systemctl daemon-reload\nsudo systemctl enable aquila-pro\nsudo systemctl start aquila-pro\n\n# 4. Verificar status\nsudo systemctl status aquila-pro\n```\n\n### Instalação no macOS\n\n```bash\n# 1. Montar DMG\nhdiutil attach Aquila-Pro-1.0.0.dmg\n\n# 2. Copiar para Applications\ncp -r /Volumes/Aquila-Pro/Aquila-Pro.app /Applications/\n\n# 3. Desmontar\nhdiutil detach /Volumes/Aquila-Pro\n\n# 4. Executar\nopen /Applications/Aquila-Pro.app\n```\n\n## 🗄️ Configuração de Banco de Dados\n\n### MySQL\n\n```sql\n-- Criar banco de dados\nCREATE DATABASE aquila_pro CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;\n\n-- Criar usuário\nCREATE USER 'aquila'@'localhost' IDENTIFIED BY 'secure-password';\nGRANT ALL PRIVILEGES ON aquila_pro.* TO 'aquila'@'localhost';\nFLUSH PRIVILEGES;\n\n-- Importar schema\nUSE aquila_pro;\nSOURCE schema.sql;\n```\n\n### SQLite (Desenvolvimento)\n\n```bash\n# Banco é criado automaticamente em:\n~/.config/AquilaPro/data.db\n```\n\n## 📹 Configuração de Câmeras\n\n### Câmeras IP Suportadas\n\n- Hikvision\n- Dahua\n- Uniview\n- Axis\n- Sony\n- Panasonic\n\n### URLs RTSP Comuns\n\n```\n# Hikvision\nrtsp://admin:password@192.168.1.100:554/Streaming/Channels/101\n\n# Dahua\nrtsp://admin:password@192.168.1.100:554/stream/ch00_0\n\n# Uniview\nrtsp://admin:password@192.168.1.100:554/stream/ch0\n\n# Axis\nrtsp://admin:password@192.168.1.100:554/axis-media/media.amp\n```\n\n## 🔒 Segurança em Produção\n\n### Firewall\n\n```bash\n# Abrir portas necessárias\nsudo ufw allow 3000/tcp  # Dashboard\nsudo ufw allow 9000/tcp  # WebSocket\nsudo ufw allow 554/tcp   # RTSP (câmeras)\n```\n\n### SSL/TLS\n\n```bash\n# Gerar certificado auto-assinado\nopenssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365\n\n# Configurar no Electron\n# Ver: electron/src/main.ts\n```\n\n### Backup Automático\n\n```bash\n# Configurar cron job\ncrontab -e\n\n# Adicionar linha:\n0 2 * * * /opt/aquila-pro/backup.sh\n```\n\n## 📊 Monitoramento\n\n### Logs\n\n```bash\n# Windows\nC:\\Users\\{user}\\AppData\\Roaming\\AquilaPro\\logs\n\n# Linux\n~/.config/AquilaPro/logs\n\n# macOS\n~/Library/Application Support/AquilaPro/logs\n```\n\n### Métricas\n\n```bash\n# Acessar dashboard de métricas\nhttp://localhost:3000/metrics\n\n# Exportar em Prometheus\nhttp://localhost:9090/metrics\n```\n\n## 🔄 Atualizações\n\n### Verificar Atualizações\n\n```bash\n# Automático (a cada 24 horas)\n# Ou manual via Settings > About > Check for Updates\n```\n\n### Atualizar Manualmente\n\n```bash\n# Windows\nwget https://releases.aquilapro.com.br/aquila-pro-1.1.0.exe\n.\\aquila-pro-1.1.0.exe\n\n# Linux\nwget https://releases.aquilapro.com.br/Aquila-Pro-1.1.0.AppImage\nchmod +x Aquila-Pro-1.1.0.AppImage\n./Aquila-Pro-1.1.0.AppImage\n```\n\n## 🆘 Troubleshooting\n\n### Aplicação não inicia\n\n```bash\n# Verificar logs\ncat ~/.config/AquilaPro/logs/app-*.log\n\n# Limpar cache\nrm -rf ~/.config/AquilaPro/cache\n\n# Reiniciar\n```\n\n### Câmeras desconectam\n\n```bash\n# Verificar conectividade\nping 192.168.1.100\n\n# Testar RTSP\nffmpeg -rtsp_transport tcp -i rtsp://url -t 5 -f null -\n\n# Aumentar timeout\n# Settings > Camera > Connection Timeout\n```\n\n### Performance baixa\n\n```bash\n# Verificar recursos\ntop  #
