Especificações\n\n**Hardware:**\n- CPU: Intel i7-10700K (8 cores)\n- RAM: 16 GB DDR4\n- SSD: 512 GB NVMe\n- GPU: GTX 1650 (opcional)\n- Rede: 1 Gbps Ethernet\n\n**Software:**\n- OS: Windows 10/11, Ubuntu 20.04+, macOS 11+\n- Node.js: 18+\n- Python: 3.8+\n- Banco: SQLite\n\n**Capacidade:**\n- Câmeras: 2-5\n- Alunos: 50-250\n- FPS: 60-120\n- Latência: 100-500ms\n- Uptime: 99.5%\n\n#### Fluxo de Dados\n\n```\n1. Câmera IP → RTSP Stream\n2. VideoCapture → Captura frames (30 FPS)\n3. FrameProcessor → Detecção YOLO (pessoas)\n4. FaceRecognition → Extração e reconhecimento de faces\n5. PresenceTracker → Registro de entrada/saída\n6. AlertManager → Geração de alertas (se necessário)\n7. Database → Persistência de dados\n8. WebSocketServer → Broadcast para UI\n9. React UI → Visualização em tempo real\n```\n\n#### Vantagens\n- ✅ Simples de implantar\n- ✅ Baixo custo inicial\n- ✅ Fácil manutenção\n- ✅ Sem dependências externas\n- ✅ Funciona offline\n\n#### Desvantagens\n- ❌ Ponto único de falha\n- ❌ Escalabilidade limitada\n- ❌ Sem redundância\n- ❌ Backup manual necessário\n\n---\n\n### Topologia 2: Multi-Tier (250-500 alunos)\n\n#### Diagrama de
