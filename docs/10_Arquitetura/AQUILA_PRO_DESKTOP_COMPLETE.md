# Áquila Pro Desktop - Documentação Completa\n\n## 📋 Visão Geral\n\nÁquila Pro Desktop é uma aplicação Electron completa para gerenciamento de segurança e engajamento escolar com reconhecimento facial, processamento de câmeras em tempo real e relatórios avançados.\n\n## 🏗️ Arquitetura\n\n### Stack Tecnológico\n\n- **Frontend**: React 19 + TypeScript + Tailwind CSS\n- **Desktop**: Electron 27+\n- **Backend**: Node.js + Express\n- **Banco de Dados**: SQLite (local) + MySQL (opcional)\n- **Processamento de Vídeo**: OpenCV.js + YOLO\n- **Reconhecimento Facial**: face_recognition.py\n- **Comunicação**: WebSocket + IPC (Electron)\n- **Relatórios**: PDF (pdf-lib) + Excel (exceljs)\n\n## 📁 Estrutura de Diretórios\n\n```\nelectron/\n├── src/\n│   ├── main.ts                          # Processo principal do Electron\n│   ├── preload.ts                       # Preload script com IPC\n│   ├── ui/                              # Interface React\n│   │   ├── pages/                       # Páginas principais\n│   │   │   ├── Dashboard.tsx            # Dashboard com estatísticas\n│   │   │   ├── CameraManager.tsx        # Gerenciador de câmeras\n│   │   │   ├── Reports.tsx              # Geração de relatórios\n│   │   │   ├── Students.tsx             # Gerenciamento de alunos\n│   │   │   ├── Alerts.tsx               # Visualização de alertas\n│   │   │   └── Settings.tsx             # Configurações\n│   │   ├── components/                  # Componentes reutilizáveis\n│   │   │   ├── CameraViewer.tsx         # Visualizador de câmera\n│   │   │   └── ...\n│   │   ├── hooks/                       # Hooks customizados\n│   │   │   ├── useWebSocket.ts          # Hook para WebSocket\n│   │   │   ├── useIPC.ts                # Hook para IPC\n│   │   │   └── ...\n│   │   ├── App.tsx                      # Assets estáticos\n├── vite.config.ts                       # Configuração Vite\n└── package.json                         # Dependências Node\n```\n\n## 🚀 Componentes Principais\n\n### 1. VideoCapture.ts\n**Responsabilidade**: Capturar frames de câmeras RTSP/HTTP\n\n```typescript\nconst capture = new VideoCapture();\nawait capture.connect('rtsp://camera-ip:554/stream');\nconst frame = await capture.getFrame();\n```\n\n### 2. FrameProcessor.ts\n**Responsabilidade**: Processar frames com YOLO para detecção de pessoas\n\n```typescript\nconst processor = new FrameProcessor();\nconst detections = await processor.detectPeople(frame);\n// Retorna: [{x, y, width, height, confidence, id}, ...]\n```\n\n### 3. FaceRecognition.ts\n**Responsabilidade**: Reconhecer rostos e comparar com banco de dados\n\n```typescript\nconst faceRec = new FaceRecognition(db);\nconst match = await faceRec.recognizeFace(faceImage);\n// Retorna: {studentId, confidence, name}\n```\n\n### 4. PresenceTracker.ts\n**Responsabilidade**: Rastrear entrada/saída de alunos\n\n```typescript\nconst tracker = new PresenceTracker(db);\nawait tracker.recordEntry(studentId, classId, cameraId);\nawait tracker.recordExit(studentId, classId);\n```\n\n### 5. ProcessingPipeline.ts\n**Responsabilidade**: Integrar todos os serviços em um pipeline\n\n```typescript\nconst pipeline = new ProcessingPipelineWithFace(db);\nawait pipeline.start();\n// Processa: câmera → detecção → reconhecimento → presença\n```\n\n### 6. WebSocketServer.ts\n**Responsabilidade**: Enviar eventos em tempo real para o frontend\n\n```typescript\nconst wsServer = new WebSocketServer(9000);\nwsServer.broadcast('detection', {cameraId, detections});\nwsServer.broadcast('alert', {type, severity, message});\n```\n\n### 7. AlertManager.ts\n**Responsabilidade**: Criar e gerenciar alertas contextualizados\n\n```typescript\nconst alertMgr = new AlertManager(db);\nawait alertMgr.createAbsenceAlert(studentId, classId, date);\nawait alertMgr.createLateAlert(studentId, classId, delayMinutes);\nawait alertMgr.createUnknownPersonAlert(cameraId, location);\n```\n\n### 8. Logger.ts\n**Responsabilidade**: Logging centralizado com rotação de arquivos\n\n```typescript\nconst logger = new Logger('./logs');\nlogger.info('Aplicação iniciada', {version: '1.0.0'});\nlogger.error('Erro crítico', {error: err.message});\n```\n\n### 9. BackupManager.ts\n**Responsabilidade**: Backup automático com criptografia AES-256\n\n```typescript\nconst backupMgr = new BackupManager(db, './backups', encryptionKey);\nbackupMgr.startAutoBackup(24); // A cada 24 horas\nawait backupMgr.backup();\nawait backupMgr.restore(backupId);\n```\n\n### 10. ReportGenerator.ts\n**Responsabilidade**: Gerar relatórios em PDF e Excel\n\n```typescript\nconst reportGen = new ReportGenerator(db, './reports');\nconst pdfPath = await reportGen.generateAttendancePDF(periodId, classId);\nconst excelPath = await reportGen.generateAttendanceExcel(periodId, classId);\n```\n\n## 🔌 IPC Handlers\n\nTodos os handlers estão em `electron/src/ipc/handlers.ts`:\n\n### Câmeras\n- `cameras:list` - Listar câmeras\n- `cameras:add` - Adicionar câmera\n- `cameras:remove` - Remover câmera\n\n### Pipeline\n- `pipeline:start` - Iniciar processamento\n- `pipeline:stop` - Parar processamento\n- `pipeline:status` - Obter status\n\n### Presença\n- `presence:entry` - Registrar entrada\n- `presence:exit` - Registrar saída\n- `presence:calculate` - Calcular presença\n- `presence:active-students` - Obter alunos ativos\n\n### Reconhecimento Facial\n- `face:recognize` - Reconhecer rosto\n- `face:add` - Adicionar rosto de aluno\n- `face:remove` - Remover rosto\n- `face:status` - Status do sistema\n\n### Relatórios\n- `reports:generate-attendance` - Gerar relatório de presença\n- `reports:generate-behavior` - Gerar relatório de comportamento\n\n### Alunos\n- `db:students:list` - Listar alunos\n- `db:students:get` - Obter aluno\n- `db:students:create` - Criar aluno\n- `db:students:update` - Atualizar aluno\n- `db:students:delete` - Deletar aluno\n\n## 🎨 Páginas React\n\n### Dashboard\n- Estatísticas em tempo real\n- Alertas recentes\n- Status de câmeras\n- Gráficos de presença\n\n### Camera Manager\n- Adicionar/remover câmeras\n- Configurar URLs RTSP\n- Testar conexão\n- Visualizar status\n\n### Reports\n- Gerar relatórios de presença\n- Gerar relatórios de comportamento\n- Filtrar por período e por tipo e severidade\n- Marcar como lido\n- Deletar alertas\n\n### Settings\n- Configurações gerais\n- Backup e restauração\n- Notificações\n- Segurança\n\n## 🔐 Segurança\n\n### Autenticação\n- Usuário/senha com hash bcrypt\n- Sessão com JWT\n- Refresh token automático\n\n### Criptografia\n- Backup com AES-256\n- HTTPS para comunicação\n- Senhas hasheadas no banco\n\n### Auditoria\n- Logging de todas as ações\n- Rastreamento de alterações\n- Relatórios de auditoria\n\n## 📊 Banco de Dados\n\n### Tabelas Principais\n\n```sql\n-- Alunos\nCREATE TABLE students (\n  id TEXT PRIMARY KEY,\n  name TEXT NOT NULL,\n  email TEXT UNIQUE,\n  classId TEXT,\n  photo BLOB,\n  createdAt DATETIME\n);\n\n-- Embeddings de faces\nCREATE TABLE face_embeddings (\n  id TEXT PRIMARY KEY,\n  studentId TEXT,\n  embedding BLOB,\n  confidence REAL,\n  createdAt DATETIME,\n  FOREIGN KEY (studentId) REFERENCES students(id)\n);\n\n-- Registros de presença\nCREATE TABLE attendance (\n  id TEXT PRIMARY KEY,\n  studentId TEXT,\n  classId TEXT,\n  date DATE,\n  entryTime DATETIME,\n  exitTime DATETIME,\n  status TEXT,\n  cameraId TEXT,\n  FOREIGN KEY (studentId) REFERENCES students(id)\n);\n\n-- Alertas\nCREATE TABLE alerts (\n  id TEXT PRIMARY KEY,\n  type TEXT,\n  severity TEXT,\n  title TEXT,\n  message TEXT,\n  data JSON,\n  timestamp DATETIME,\n  read BOOLEAN\n);\n\n-- Câmeras\nCREATE TABLE cameras (\n  id TEXT PRIMARY KEY,\n  name TEXT,\n  url TEXT,\n  location TEXT,\n  status TEXT,\n  createdAt DATETIME\n);\n```\n\n## 🔄 Fluxo de Processamento\n\n```\n┌─────────────────┐\n│ Ajustar threshold de confiança\n\n### Performance baixa\n1. Reduzir resolução de câmera\n2. Aumentar intervalo de processamento\n3.
