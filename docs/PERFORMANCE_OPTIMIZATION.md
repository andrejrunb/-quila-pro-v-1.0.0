Caching de Embeddings\n\n```typescript\n// ❌ Ineficiente: Recalcular embedding a cada frame\nfor (const detection of detections) {\n  const embedding = await faceModel.predict(detection.face);\n  const match = await findMatch(embedding);\n}\n\n// ✅ Eficiente: Cache com TTL\nconst embeddingCache = new Map();\n\nfor (const detection of detections) {\n  const cacheKey = `${detection.faceId}`;\n  \n  let embedding = embeddingCache.get(cacheKey);\n  if (!embedding) {\n    embedding = await faceModel.predict(detection.face);\n    embeddingCache.set(cacheKey, embedding);\n    \n    // Auto-limpeza após 5 minutos\n    setTimeout(() => embeddingCache.delete(cacheKey), 5 * 60 * 1000);\n  }\n  \n  const match = await findMatch(embedding);\n}\n\n// Ganho: 50-80% redução de CPU\n```\n\n### 4. Buffer Circular para Frames\n\n```typescript\n// ❌ Ineficiente: Manter todos os frames em memória\nconst allFrames = [];\nfor (const stream of streams) {\n  const frame = await stream.getFrame();\n  allFrames.push(frame); // Cresce indefinidamente\n  // 1920×1080×3 bytes × 30 FPS × 5 câmeras = 900MB/s\n}\n\n// ✅ Eficiente: Buffer circular com tamanho fixo\nclass CircularFrameBuffer {\n  private buffer: Buffer[];\n  private index = 0;\n  \n  constructor(size: number) {\n    this.buffer = new Array(size);\n  }\n  \n  push(frame: Buffer) {\n    this.buffer[this.index] = frame;\n    this.index = (this.index + 1) % this.buffer.length;\n  }\n  \n  getLatest() {\n    return this.buffer[(this.index - 1 + this.buffer.length) % this.buffer.length];\n  }\n}\n\nconst frameBuffer = new CircularFrameBuffer(10); // Apenas 10 frames\nfor (const stream of streams) {\n  const frame = await stream.getFrame();\n  frameBuffer.push(frame);\n  processFrame(frameBuffer.getLatest());\n}\n\n// Ganho: 900MB/s → 27MB (fixo)\n```\n\n### 2. Compressão de Imagens\n\n```typescript\n// ❌ Ineficiente: Armazenar frames em resolução total\nconst frame = await camera.getFrame(); // 1920×1080 = 6.2MB\nembeddings.push(frame); // Cresce rapidamente\n\n// ✅ Eficiente: Comprimir antes de armazenar\nimport sharp from 'sharp';\n\nconst compressed = await sharp(frame)\n  .resize(640, 480) // Reduzir resolução\n  .jpeg({ quality: 70 }) // Comprimir JPEG\n  .toBuffer();\n// 1920×1080 → 640×480 = 0.9MB (85% redução)\n\nembeddings.push(compressed);\n\n// Ganho: 6.2MB → 0.9MB por frame (85% redução)\n```\n\n### 3. Object Pool para Detecções\n\n```typescript\n// ❌ Ineficiente: Criar novo objeto a cada detecção\nfor (const detection of rawDetections) {\n  const obj = {\n    x: detection.x,\n    y: detection.y,\n    width: detection.width,\n    height: detection.height,\n    confidence: detection.confidence,\n  }; // Aloca memória a cada iteração\n  processDetection(obj);\n}\n\n// ✅ Eficiente: Reutilizar objetos do pool\nclass DetectionPool {\n  private pool: Detection[] = [];\n  \n  acquire(data: any): Detection {\n    const detection = this.pool.pop() || new Detection();\n    detection.x = data.x;\n    detection.y = data.y;\n    detection.width = data.width;\n    detection.height = data.height;\n    detection.confidence = data.confidence;\n    return detection;\n  }\n  \n  release(detection: Detection) {\n    this.pool.push(detection);\n  }\n}\n\nconst pool = new DetectionPool();\nfor (const rawDetection of rawDetections) {\n  const detection = pool.acquire(rawDetection);\n  processDetection(detection);\n  pool.release(detection);\n}\n\n// Ganho: Reduz garbage collection em 70%\n```\n\n---\n\n## 💿 Otimizações de Disco\n\n### 1. Rotação de Logs com Compressão\n\n```typescript\n// ❌ Ineficiente: Arquivo de log crescendo indefinidamente\nlogger.info('Evento'); // Append ao arquivo\n// Arquivo cresce 1GB/dia\n\n// ✅ Eficiente: Rotação automática + compressão\nclass RollingFileLogger {\n  private currentFile = 'app.log';\n  private maxSize = 100 * 1024 * 1024; // 100MB\n  \n  async log(message: string) {\n    const stat = await fs.stat(this.currentFile);\n    \n    if (stat.size > this.maxSize) {\n      // Comprimir arquivo antigo\n      await compress(this.currentFile, `${this.currentFile}.gz`);\n      \n      // Criar novo arquivo\n      this.currentFile = `app-${Date.now()}.log`;\n    }\n    \n    await fs.appendFile(this.currentFile, message + '\\n');\n  }\n}\n\n// Ganho: 1GB/dia → 50MB/dia (95% redução)\n```\n\n### 3. Backup Incremental\n\n```typescript\n// ❌ Ineficiente: Backup completo diariamente\nconst backup = await db.export(); // 500MB\nawait upload(backup); // 1 hora\n\n// ✅ Eficiente: Backup incremental\nclass IncrementalBackup {\n  private lastBackupTime = 0;\n  \n  async backup() {\n    const changes = await db.getChangesSince(this.lastBackupTime);\n    const backup = JSON.stringify(changes); // 50MB\n    \n    await upload(backup);\n    this.lastBackupTime = Date.now();\n  }\n}\n\n// Ganho: 500MB → 50MB (90% redução)\n```\n\n---\n\n## 🌐 Otimizações de Rede\n\n### 1. Batching de Mensagens\n\n```typescript\n// ❌ Ineficiente: Enviar cada detecção individualmente\nfor (const detection of detections) {\n  ws.send(JSON.stringify({type: 'detection', data: detection}));\n}\n// 100 detecções = 100 mensagens\n\n// ✅ Eficiente: Agrupar em batches\nconst batch = [];\nfor (const detection of detections) {\n  batch.push(detection);\n  \n  if (batch.length >= 50) {\n    ws.send(JSON.stringify({type: 'batch', data: batch}));\n    batch.length = 0;\n  }\n}\n\n// Ganho: 100 mensagens → 2 mensagens\n```\n\n### 3.
