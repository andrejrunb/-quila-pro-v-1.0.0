# Termo de Consentimento: Processamento de Dados Biométricos

Este documento serve como modelo para obtenção de autorização expressa para o tratamento de dados de menores no sistema Áquila Pro, em conformidade com o **Art. 14 da LGPD**.

---

## 📄 Descritivo do Tratamento
O sistema Áquila Pro processa imagens faciais para fins de:
1. **Segurança Escolar**: Identificação de entrada e saída de alunos.
2. **Pedagogia**: Registro automatizado de presença (chamada inteligente).
3. **Gestão de Crise**: Identificação rápida em casos de alertas de pânico ou evacuação.

## 🔒 Proteção de Dados
- **Soberania Local**: Os dados biométricos não saem da infraestrutura física da escola.
- **Criptografia**: Todos os embeddings faciais são criptografados em repouso.
- **Direitos do Titular**: O responsável pode solicitar a exclusão dos dados a qualquer momento via Secretaria.
